POENGLØP v2.12 – INSTALLASJON PÅ NY PC
=====================================

Poengløp beregner poeng og tid for lommelyktløp ut fra Brikkesys.
Programmet leser bare fra Brikkesys og endrer aldri noe der.

DU TRENGER
- Windows-PC der Brikkesys (MySQL) er installert
- Brukernavn og passord til MySQL-databasen (database: resultatdatabase)
- Internett én gang under installasjonen (for Node.js og MySQL-driveren)

1. INSTALLER NODE.JS
   Last ned LTS-versjonen fra https://nodejs.org og installer med standardvalg.
   Logg av og på Windows etterpå.

2. PAKK UT
   Pakk ut zip-filen til C:\Poenglop, slik at du får:
     C:\Poenglop\Poenglop_v2.12
     C:\Poenglop\Poenglop_BrikkesysAPI_v1.4
   IKKE bruk C:\Program Files (gir feilen EPERM).

3. LEGG INN DATABASEPASSORD
   Åpne C:\Poenglop\Poenglop_BrikkesysAPI_v1.4\poeng-brikkesys-config.json i Notisblokk.
   Fyll inn "user" og "password". Kontroller at "database" er resultatdatabase. Lagre.

4. TEST TILKOBLINGEN
   Dobbeltklikk 0_Test_tilkobling.bat i API-mappen.
   Første gang lastes MySQL-driveren ned. Riktig resultat:
     "Tilkoblet resultatdatabase på 127.0.0.1:3306 ... N tabeller"

5. START POENGLØP
   Dobbeltklikk C:\Poenglop\Poenglop_v2.12\Start_Poenglop.bat.
   Nettleseren åpner Poengløp, og løpene vises i nedtrekksmenyen øverst til høyre.
   Poengløp leser MySQL direkte med brukernavnet fra steg 3. Fungerer ikke det,
   startes Brikkesys-API automatisk. Se Oppsett -> Tilkobling til Brikkesys.
   Det svarte vinduet må stå åpent mens Poengløp brukes.

6. FØRSTE GANG: KONTROLLER OPPSETTET
   - Kommer meldingen "Oppsettet av tabeller passer ikke": trykk "Finn tabeller automatisk" og "Bruk forslaget".
   - Velg et løp og se på Oppsett -> Målpost. To grønne haker betyr at målposten fra classes.codes er funnet og stemmer med stemplingene.
   - Prøv gjerne testløpene nederst i nedtrekksmenyen, med TEST_poengoppsett.json (Hent poengoppsett fra fil).

FULL BRUKSANVISNING: fanen "Bruksanvisning" i Poengløp.

SIKKERHET
- Poengløp og API-et kan bare nås fra denne PC-en (127.0.0.1). Andre nettsider kan ikke lese dataene.
- Passordet står i klartekst i poeng-brikkesys-config.json. Del aldri denne filen.
  Anbefalt: egen MySQL-bruker med bare lesetilgang:
    CREATE USER 'poeng'@'localhost' IDENTIFIED BY 'velg-et-passord';
    GRANT SELECT ON resultatdatabase.* TO 'poeng'@'localhost';
- Eksporterte CSV-filer inneholder personopplysninger. Slett dem etter bruk.

VANLIGE FEIL
- 'node' is not recognized      -> Node.js er ikke installert, eller du har ikke logget av og på.
- npm error EPERM               -> Mappen ligger i C:\Program Files. Flytt til C:\Poenglop.
- Access denied for user        -> Feil brukernavn/passord i poeng-brikkesys-config.json.
- ECONNREFUSED 127.0.0.1:3306   -> MySQL/Brikkesys kjører ikke.
- Port 8090 er i bruk           -> Poengløp kjører allerede i et annet vindu.
- Æ, ø, å vises feil            -> Sett "charset" til "latin1" i poeng-brikkesys-config.json.
